# Chandan Pal — Portfolio

A React and TypeScript portfolio for Chandan Pal, focused on product engineering, technical leadership, and experimental web work.

## Local development

Requires Node.js 20+.

1. `npm install`
2. `npm run dev`
3. Open `http://localhost:3000`

## Quality checks

- `npm run lint` — TypeScript check
- `npm run build` — production build

## Before deployment

- Confirm that all social and project links are correct.
- Add public demos, repositories, screenshots, or verified outcome metrics to case studies where permission allows.
- Add an Open Graph image and canonical production URL to `index.html`.
